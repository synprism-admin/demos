Accessibility Statement

Last updated: January 1, 2025

EG Koch Travel is committed to ensuring that our website is accessible to all visitors, including people with disabilities. We strive to meet the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standards.

Our Commitment

We are actively working to improve the accessibility of our website by:

  • Providing descriptive alt text for all meaningful images
  • Ensuring sufficient color contrast throughout the site
  • Using clear, readable font sizes and legible typography
  • Making all interactive elements accessible via keyboard navigation
  • Using proper semantic HTML structure (headings, labels, landmarks)
  • Ensuring forms have clearly labeled fields
  • Providing focus indicators for keyboard users

Known Limitations

While we work to ensure the highest level of accessibility, some content may not yet fully meet all WCAG 2.1 AA criteria. We are continuously improving and welcome feedback about any barriers you encounter.

California Accessibility Laws

This site is operated from California and we are mindful of accessibility obligations under California law, including the Unruh Civil Rights Act (Civil Code §51), which requires equal access for persons with disabilities, and the California Government Code §11135, which addresses accessibility for programs receiving state funding. We aim to meet these obligations through our ongoing accessibility efforts.

Assistive Technology Compatibility

This website is designed to be compatible with common assistive technologies, including:

  • Screen readers (NVDA, JAWS, VoiceOver, TalkBack)
  • Keyboard-only navigation
  • Browser zoom and text resizing tools
  • High contrast display modes
