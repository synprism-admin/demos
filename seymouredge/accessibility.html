Accessibility Statement

Last updated: August 2026

The EDGE Homeschool Co-op is committed to ensuring digital accessibility for people with disabilities. We continually improve the user experience for everyone and apply relevant accessibility standards.

Conformance Status

This website aims to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. These guidelines explain how to make web content more accessible to people with disabilities.

Measures We Take

  • Using semantic HTML5 elements throughout the site
  • Providing meaningful alt text for all images
  • Ensuring sufficient color contrast between text and backgrounds
  • Making all interactive elements keyboard-navigable
  • Including skip-to-content links for screen readers
  • Using ARIA labels where appropriate

Known Limitations

We are working to identify and resolve any remaining accessibility issues. This is an ongoing effort, and we welcome feedback.

Feedback

We welcome your feedback on the accessibility of this site. If you experience any barriers, please contact us via the EDGE website. We will try to respond within 2 business days.

Technical Specifications

This website relies on the following technologies for conformance: HTML, CSS, JavaScript. These technologies are relied upon for conformance with the accessibility standards used.

Assessment Approach

The EDGE assessed the accessibility of this site by self-evaluation using browser accessibility tools and screen reader testing.

Formal Complaints

If you are not satisfied with our response, you may contact the Tennessee Human Rights Commission or the U.S. Department of Justice's ADA Information Line at 1-800-514-0301.
